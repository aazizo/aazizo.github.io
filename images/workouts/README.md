Workout visual assets
=====================

The still images, movement GIFs, and muscle-highlight SVGs in this folder were
matched per exercise from the public Anatome API.

Attribution:
- Exercise data/images: free-exercise-db by yuhonas, CC0-1.0 public domain.
- API and muscle-map rendering: Anatome, Apache-2.0.

The local `manifest.json` records the resolved source exercise for each app
exercise name.
